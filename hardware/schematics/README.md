Schematics

This directory was a placeholder before either board had real schematic
work. Both now live under `hardware/pcb/`, alongside their PCB layout
(where one exists) rather than as separate PDF exports:

- `hardware/pcb/main-board/` — Board 2 (Main Board): KiCad schematic +
  routed, DRC-clean PCB.
- `hardware/pcb/plc-board/` — Board 1 (PLC/Power Board, the PLC
  Adapter's PCB): KiCad schematic for the well-specified parts; no PCB
  layout yet, see that directory's README for what's still missing.

This directory is kept as a pointer rather than removed, in case
something still links here.
